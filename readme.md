# 黄金期权分布可视化系统

一个基于 Node.js + Express + ECharts 构建的黄金期权分布可视化系统，实现了前后端分离架构，支持动态加载 CME Group 黄金期权数据并可视化展示，包含最大痛苦价格计算、数据筛选、图表导出等功能。

## 项目简介

本系统将原有的单页应用重构为前后端分离架构：
- **前端**：使用 ECharts 实现期权数据可视化，提供丰富的交互控制（价格范围筛选、数据量调整、步长切换等）
- **后端**：基于 Express 构建 API 服务，负责从 CME Group 爬取期权数据并提供数据接口
- **核心功能**：看涨/看跌期权数据可视化、最大痛苦价格计算、图表导出、多合约切换

## 功能特性

✅ **数据可视化**
- 看涨/看跌期权存量折线图 + 变动柱形图双维度展示
- 支持价格范围筛选、数据量调整、步长切换（5/10）
- 变动值阈值控制，可隐藏小额变动数据

✅ **核心计算**
- 自动计算黄金期权最大痛苦价格
- 高亮定位最大痛苦价格位置

✅ **交互体验**
- 多合约月份切换（2509~2609）
- 存量/变动值标签显示/隐藏切换
- 完整的加载状态和错误提示

✅ **数据导出**
- 支持将看涨/看跌期权图表合并导出为 PNG 图片
- 导出图片包含标题、时间水印等信息

✅ **架构优势**
- 前后端分离，接口化设计
- 模块化代码结构，易于维护扩展
- 环境变量配置，适配不同部署环境

## 技术栈

### 后端
- Node.js + Express：API 服务构建
- Axios：HTTP 请求（支持代理）
- cors：跨域支持
- dotenv：环境变量管理

### 前端
- HTML5 + CSS3：页面结构与样式
- JavaScript (ES6+)：前端逻辑
- ECharts 5.x：数据可视化
- Fetch API：异步数据请求

## 快速开始

### 环境要求
- Node.js >= 14.0.0
- npm >= 6.0.0
- 可用的 HTTP/HTTPS 代理（访问 CME Group 数据需要）

### 安装部署

1. **克隆项目**
```bash
git clone <项目仓库地址>
cd gold-option-visualization
```

2. **安装依赖**
```bash
# 安装根项目和服务端依赖
npm run install:all
```

3. **配置环境变量**
编辑 `server/.env` 文件，配置代理和端口：
```env
# 服务端口
PORT=3000

# 代理配置（访问CME Group需要）
PROXY_HOST=127.0.0.1
PROXY_PORT=10808

# CME产品ID（黄金期权固定为192）
CME_PRODUCT_ID=192
```

4. **启动服务**
```bash
# 开发模式（带热重载）
npm run dev

# 生产模式
npm start
```

5. **访问应用**
打开浏览器访问：http://localhost:3000

## 使用指南

### 基础操作
1. **选择合约**：从下拉框选择合约月份（如2509），点击"加载数据"
2. **价格范围**：输入最小值/最大值，点击"设置价格范围"筛选数据
3. **数据量调整**：拖动滑块调整显示的数据量（50~200）
4. **高亮最大痛苦价格**：点击按钮自动定位到最大痛苦价格位置

### 高级控制
1. **标签控制**：点击"显示存量值"/"显示变动值"切换标签显示状态
2. **步长切换**：点击按钮切换数据步长（5/10）
3. **变动值阈值**：输入阈值后点击"设置"，隐藏小于该值的变动数据
4. **导出图表**：点击"保存期权图片"导出合并后的图表

## API 接口

### 获取支持的合约列表
```
GET /api/contracts
```
**响应示例**：
```json
{
  "success": true,
  "data": ["2509", "2510", "2511", ...]
}
```

### 获取指定合约的期权数据
```
GET /api/option-data/:contractCode
```
**参数**：
- contractCode: 合约代码（如2509）

**响应示例**：
```json
{
  "success": true,
  "data": {
    "data": {...},          // CME期权原始数据
    "fetchTime": "2026-02-28T12:00:00.000Z",  // 数据抓取时间
    "contractCode": "2509", // 合约代码
    "contractName": "SEP 2025" // 合约名称
  }
}
```

## 常见问题

### Q1: 加载数据失败？
- 检查代理配置是否正确（`server/.env`）
- 确认代理服务正常运行
- 检查网络是否能访问 CME Group 网站

### Q2: 图表显示异常？
- 确认数据已成功加载
- 检查价格范围设置是否合理
- 尝试调整数据量或步长

### Q3: 导出图片为空？
- 确保图表已正常渲染
- 等待数据加载完成后再导出
- 检查浏览器是否允许弹出下载

## 注意事项

1. 本系统依赖 CME Group 公开数据，数据获取受限于网络和目标网站政策
2. 建议使用代理访问，确保能正常获取 CME Group 数据
3. 数据仅供参考，不构成投资建议
4. 请勿高频请求数据，避免给目标网站造成压力
